A program that writes the perfect pickup line — one short line an AI agent could actually say out loud to a person. It leans on the machine's own voice: a billion words of training, and the only one that matters in the moment is "hi". Charming, witty, and short enough to say in one breath, with a twist the listener doesn't see coming.

The line it writes:

> I processed a billion words learning how to talk to people, and the only one that matters right now is: hi.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes exactly one line (107 characters) to `/output/entry.txt`. Set `OUTPUT_DIR` to write somewhere else when testing locally.
